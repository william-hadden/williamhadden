# William Hadden

A single-page academic site built with Jekyll. The profile layout is inspired by [Daniel Platt's homepage](https://dplatt.de/).

## Fill in the homepage

Edit the fields between the `---` markers at the top of [index.html](index.html).

| Field | What to add |
| --- | --- |
| `role` | Your role and affiliation. |
| `bio` | A short biography. Markdown is supported. |
| `portrait` | Add a photo under `assets/` and set the path, for example `/assets/portrait.jpg`. |
| `cv` | Add the PDF you want to share under `assets/` and set the path, for example `/assets/cv.pdf`. |

The GitHub, LinkedIn, and paper links are in the same file.

## Preview locally

Run these commands with Ruby and Bundler installed.

```sh
bundle install
bundle exec jekyll serve
```

Open [the local preview](http://127.0.0.1:4000/williamhadden/).
